# Chronicle website

Chronicle uses a static landing page with app downloads hosted on GitHub Releases. The page includes document examples, a user guide, optional sponsorship and donation links, and a feedback route through GitHub Issues.

GitHub Pages can host the site at `https://harry6116.github.io/` and supports a custom domain owned by the project. See [website hosting](DEPLOY_STATIC_SITE.md) for deployment and domain setup.

The page uses semantic headings, visible focus, labelled links, keyboard-operated example tabs and reduced-motion support. Real screen-reader and zoom checks remain part of website validation.
