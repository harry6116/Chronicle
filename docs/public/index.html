Chronicle · Document reading for Mac and Windows

Chronicle — bringing documents to life

Turn difficult scans and documents into readable, accessible text.

Chronicle is open-source software. View the source code on GitHub.

Chronicle goes beyond standard optical character recognition (OCR). It uses AI visual understanding, primarily Google Gemini, to recover text and organise reading order, headings, and tables from handwriting, archives, newspapers, books, and comics. Save results as HTML, Word, plain text, or other formats.

Designed for keyboard and screen-reader use. AI can misread, omit, or invent text. Check important results against the original. Read the AI accuracy and privacy disclaimer.

Getting started

  1. Install Chronicle and add your own AI provider API key, or set up Private Offline Mode with Ollama.
  2. Add files, choose a document preset and output format, then select Start Reading.
  3. Review the recovered text and compare important details with the original.

Online processing sends document content to your chosen provider. Optional Private Offline Mode requires you to install Ollama and download a local model separately. It is intended for simple, clear, typed documents, not difficult scans or complex layouts. See the offline setup and limitations.
