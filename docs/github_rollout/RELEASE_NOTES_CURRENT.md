# Chronicle 2.0.0

## Highlights

- Secure API-key storage in macOS Keychain and Windows Credential Manager. On upgrade, confirm the one-time reset, then enter the keys you want to use in File > API Keys.
- Clearer PDF preflight with explainable preset suggestions, targeted page trials, and privacy and cost information.
- Article Only makes a local HTML or EPUB reading copy from supported webpage PDFs, keeping the article and headings.
- Easier-to-navigate Preferences, source-linked review, resumable collection projects, and new reading export options.

## Before you start

Choose **Remove Saved Keys** at the upgrade prompt to clear Chronicle’s previous vault entries and legacy key files. Choose **Later** to keep using Private Offline Mode while you prepare your keys. Revoke any potentially exposed key with its provider before entering a replacement.

Preflight recommendations are estimates. Check a targeted trial against the source before running a long extraction.
