# Chronicle 1.1.4

Chronicle 1.1.4 brings the new Chronicle website and direct email contact into the app.

## Website and contact

- Visit the new Chronicle website at https://harry6116.github.io/ for Mac and Windows downloads, the user guide, document examples, and release news.
- Email Michael at chronicle.vir@gmail.com for questions, feedback, or support. The website and app both include a link that opens your email app.
- Choose **Help > About Chronicle** for clearly labelled **Chronicle Website**, **Email Michael**, and **GitHub Issues** actions. The website and email address are also in selectable text for copying.
- GitHub remains available for public bug reports and questions. Posting there requires a GitHub account; emailing Michael does not.

## Optional support and accessibility

- The About dialog also offers optional one-time and monthly GitHub sponsorship. Existing Buy Me a Coffee and PayPal options remain available from the Support menu.
- Contact and support actions have separate fixed rows. Use **Tab** and **Shift+Tab** to move through the text and actions, and **Escape** to close About and return to the previous control.

Chronicle remains open-source software. Private Offline Mode still requires a separate Ollama installation and model download.
