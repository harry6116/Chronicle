# Accessibility Preferences

- Start every assistant response to the user with an H2 Markdown heading (`## ...`). This helps screen-reader users navigate directly between assistant responses with heading shortcuts, including `H` and `Shift+H` in NVDA and heading navigation in macOS VoiceOver.

# Documentation Hygiene

- Internal assistant rules, process notes, implementation constraints, and planning instructions must never appear in public-facing documents or generated project documentation. Store those rules only in their proper instruction files, memory, or rule-storage locations.
